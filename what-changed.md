# Changelog

## [Pro Version PWA Update] - 2026-10-14
### Added
- **PWA Support:** Added `manifest.json` and `sw.js` allowing the app to be installed on mobile and desktop and work completely offline.
- **App Icons:** Added 192x192 and 512x512 placeholder icons for PWA installation.
- **Deposit & Withdrawal Tracking:** Added fields for cash flows into the daily modal and aggregate them into all-time and monthly dashboards.
- **Total Equity Calculation:** Account dashboard now computes total equity based on initial capital + P&L + Deposits - Withdrawals.
- **Philippine Peso formatting:** Added `₱` symbols to the UI based on local context.
- **Dark Mode UI:** Upgraded to a Tailwind slate-based dark theme.
